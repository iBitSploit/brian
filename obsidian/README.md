# Brian Second Brain

This vault is the planning and thinking system for Brian, the open-source network and infrastructure topology platform.

Start at [[00 - Brian Home]].

## Vault rules

- Keep decisions, scope changes, and assumptions written down.
- Link implementation work to a requirement or a measurable outcome.
- Keep the MVP small enough to ship and useful enough to validate.
- Prefer evidence from users, deployments, and tests over intuition.
- Update [[06 - Backlog]] whenever a task becomes concrete.
- Record important tradeoffs in [[09 - Decisions]].
- Add meaningful work sessions to [[11 - Project Journal]].
